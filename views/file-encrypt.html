เข้ารหัสไฟล์

ใส่รหัสผ่านป้องกันไฟล์ — รองรับ PDF (มาตรฐานเข้ารหัสของ PDF เอง เปิดได้กับ Adobe Reader และโปรแกรมอ่าน PDF ทั่วไป) และ ZIP (เข้ารหัสแบบ AES-256 เปิดได้กับ 7-Zip, WinRAR, macOS Archive Utility และโปรแกรมแตกไฟล์ ZIP ทั่วไป) เท่านั้น ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีการส่งไฟล์หรือรหัสผ่านออกนอกเครื่อง

ลากไฟล์ PDF หรือ ZIP มาวางที่นี่

ฟอร์แมตที่ยังไม่รองรับ (ข้ามไว้ก่อน)

Word (.docx) / Excel (.xlsx) / PowerPoint (.pptx) — ยังไม่มี library เข้ารหัสไฟล์กลุ่มนี้ที่ทำงานได้จริงในเบราว์เซอร์ (ตัวที่มีอยู่ยังรองรับเฉพาะฝั่งเซิร์ฟเวอร์/Node.js เท่านั้น)

WinRAR (.rar) — รูปแบบไฟล์ RAR เป็นกรรมสิทธิ์ปิดของ RARLAB ไม่มีตัวสร้างไฟล์ .rar ที่ทำได้แบบ client-side ถูกกฎหมาย
