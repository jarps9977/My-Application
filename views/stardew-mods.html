อัปเดต Mod Stardew Valley

1. คัดลอกคำสั่ง
2. รันคำสั่ง
  1. กด Win + R
  2. กด Ctrl + V แล้วกด Enter
  3. หน้าต่าง PowerShell จะแสดงขั้นตอนทั้งหมด รอจนขึ้น Done. แล้วกด Enter เพื่อปิด
สิ่งที่ script ทำ
  • หา folder เกมอัตโนมัติ (Steam / GOG) ถ้าไม่เจอจะให้เลือกเอง
  • ติดตั้ง/อัปเดต SMAPI เป็นเวอร์ชันล่าสุด
  • Sync Mod ให้ตรงกับ repo รวม config.json — Mod อื่นที่ไม่อยู่ใน repo ถูกย้ายไป Mods_backup (ไม่ลบ)
  • ตั้ง Steam Launch Options ให้เปิดผ่าน SMAPI และสั่ง Steam ตรวจไฟล์เกม

ถ้าเกมหรือ Steam เปิดอยู่ script จะปิดให้อัตโนมัติ — save เกมก่อนรัน

ไม่มีไฟล์ถูกดาวน์โหลดเก็บไว้ในเครื่อง script รันจาก github.com/jarps9977/stardew-mods-builded
